# HotelPro authentication API examples

Current signup, login, role, room, booking, mock payment, and admin request examples are in [HotelPro API request examples](part-1-api.md). The importable collection is [HotelPro Part 2 API](../postman/HotelPro-Phase-2.postman_collection.json).

User types are `Ordinary` and `Admin`. Admin self-signup requires the private `ADMIN_SIGNUP_CODE`; Admin routes also require an Admin JWT.
